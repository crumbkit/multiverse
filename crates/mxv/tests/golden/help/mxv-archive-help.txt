Archive a workspace, so restore can rebuild it at the same commits.

When no workspace has the name and its archive has finished, the workspace is already archived, so mxv changes nothing and the result's state is unchanged.

Usage: mxv archive [OPTIONS]

Options:
  -w, --workspace <WORKSPACE>
          The workspace, which defaults to the one that holds the current directory

      --force
          Lose what the archive cannot keep, such as a paused merge or a file over archive_max_file, and list it in the archive

      --delete-volumes
          Delete the workspace's docker volumes and the data in them; without this flag the volumes stay for the restore

      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv archive -w reading-list --dry-run
          Print what archiving the workspace reading-list would do

Effects: destructive, idempotent, closed-world.
