Print the directory of a workspace, so `cd "$(mxv cd NAME)"` resumes it

Usage: mxv cd [OPTIONS] <NAME>

Arguments:
  <NAME>
          The name of the workspace

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv cd reading-list
          Print the directory of the workspace reading-list

Effects: read-only, closed-world.
