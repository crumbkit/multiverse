Rebuild an archived workspace at its archived commits

Usage: mxv restore [OPTIONS] <NAME>

Arguments:
  <NAME>
          The name of the archived workspace

Options:
      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv restore sample --dry-run
          Print what restoring the archived workspace sample would do

Effects: additive, not idempotent, open-world.
