Give coding agents mxv's skill

Usage: mxv skills [OPTIONS] <COMMAND>

Commands:
  install  Install mxv's skill into each agent skills directory that exists
  check    Check that each installed copy of mxv's skill matches this mxv
  print    Print mxv's skill

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `mxv skills --help` describes them.
Next: mxv skills <COMMAND> -h
