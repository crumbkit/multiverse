Delete the disposable directories, such as target/ and node_modules/, of idle workspaces.

A workspace is idle when none of its processes or containers run and no file or directory of its checkout outside the disposable directories, and no commit or staged change, changed within the idle age. The disposable directories are the ignored directories named target, node_modules, dist, build and .cache, and the paths that the `disposable` globs of the checkout's mxv.toml and of the config file match while git reports them as ignored. A directory that holds a .git entry at any depth is kept. The command deletes nothing else: no tracked file, no git data and no other ignored file. It takes each workspace's lock and checks again that the workspace is idle just before it deletes anything. A workspace that mxv cannot find, measure or clean fails alone, the others are still cleaned, and the command exits with 1. Nothing runs in the background, so a cron job or a hook runs `mxv clean --over-limit --yes` to keep the disk under the config file's `max_disposable`.

Usage: mxv clean [OPTIONS] <NAME|--all|--over-limit>

Arguments:
  [NAME]...
          The names of the workspaces to clean, separated by spaces

Options:
      --all
          Clean every idle workspace

      --over-limit
          Clean idle workspaces, oldest first, until the disposable directories of every workspace take no more than the config file's max_disposable

      --idle <AGE>
          How long a checkout must go unmodified to count as idle, such as 7d, 36h or 0s; it defaults to the config file's clean_idle, or else 7d

      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv clean --all --dry-run
          Print what cleaning every idle workspace would delete

Columns:
  name        The workspace's name.
  state       `cleaned` when the run deleted the workspace's disposable directories, `would_clean` on a dry run, or `kept`.
  freed       The bytes that the run freed, measured before and after each deletion, or the bytes that the disposable directories take on a dry run, which is 0 for a workspace that the run kept. A file with a hard link outside the deleted directory frees nothing.
  disposable  The bytes that the workspace's disposable directories took on disk before the run.
  modified    When a file or directory of the workspace's checkouts outside the disposable directories, or a commit or staged change, last changed, or null when none exists.
  reason      Why the run kept the workspace's disposable directories, or some of them, or null.
  warnings    Why a checkout's disposable set holds fewer globs than its `mxv.toml` declares, such as an invalid manifest, or null.

Columns that --long adds:
  paths    Each disposable path that the run deleted, or would delete, with its checkout's name in front, such as `app: target/`.
  skipped  Each path that the disposable set matches and that the run kept, with the reason, such as a directory that holds a `.git` entry.

Effects: destructive, idempotent, closed-world.
Writes: reports each item and exits 1 when any item fails.
