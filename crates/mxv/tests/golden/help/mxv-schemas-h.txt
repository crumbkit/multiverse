Explore the JSON documents that mxv prints

Usage: mxv schemas [OPTIONS] <COMMAND>

Commands:
  list  List the JSON documents that mxv prints, with a description of each
  show  Print the JSON Schema of each document

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `mxv schemas --help` describes them.
