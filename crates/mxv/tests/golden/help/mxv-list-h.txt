List the workspaces

Usage: mxv list [OPTIONS]

Options:
      --limit <N>  Print at most this many rows, up to 100 [default: 25]
      --all        Print every row
      --sizes      Measure each workspace's size on disk and its disposable size, which reads every file of every workspace on the page
  -h, --help       Print help (see more with '--help')

Examples:
  mxv list

Effects: read-only, closed-world.
Problems: a value in the problem column marks a row with a problem, and the command then exits with 1.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `mxv list --help` describes them.
Next: mxv list --help explains each column.
