Repair the broken records of one name that `mxv list` names `mxv repair NAME` for, or with --orphans list what no record names.

An archive that stopped before it finished, and whose pins are gone, moves aside to the hidden directory .NAME.<ID> beside the other archives, which `mxv list --archived` does not list, and its private tar of ignored files stays at $XDG_DATA_HOME/mxv/archives/<ID>/ignored.tar. They stay until `mxv repair --orphans --delete-aside` deletes them; the result names both paths. An older archive that stopped before it finished, beside a newer workspace of the same name, takes the name NAME-YYYY-MM-DD, from the day the archive started, or that name with -2 and on when it is taken, and mxv finishes it, so `mxv restore` of the dated name brings it back. When its pins are gone, it moves aside instead. When an earlier repair stopped while it moved the archive, `mxv list` names `mxv repair` of the older name on both records, a repair of either name finishes the move, and `mxv archive -w` of either name refuses with mxv::archive::rename_unfinished. An archive beside the workspace that a restore of it rebuilt, because the restore stopped before it deleted the archive, is deleted with its pins. mxv asks before each repair that changes something, and --yes repairs without asking. When the records change between the question and the repair, so that the repair would differ from the one confirmed, mxv repairs nothing and fails with mxv::repair::changed. A name with nothing broken, or with a problem that another command repairs, changes nothing, and the result names that command. Each repair can run again after it stops partway.

With --orphans and no NAME, mxv lists, with its size, each item that no record names. The run files of a name that no workspace has, and phase's run record and logs of a workspace id that no workspace or archive record holds, are mxv's derived state, so mxv deletes them after you confirm. Before it deletes a run record, phase's sweep stops the processes and removes the containers, networks and run volumes that it names; a process that phase cannot stop keeps the record and the logs, and its row names the process. The docker volumes that hold the data of such an id stay unless you pass --delete-volumes. Each archive that a repair moved aside, and each directory of ignored files at $XDG_DATA_HOME/mxv/archives/<ID> whose archive no record names, such as the one of a moved-aside archive whose directory you deleted by hand, holds the only copies of its files, so mxv deletes them only with --delete-aside, and --yes only skips the question. A directory of the archives without its own record, such as a hidden one without the record of the archive that its name names, is listed as kept and never deleted. The listing and --dry-run take no lock and write nothing. When a workspace or archive record cannot be read, a moved-aside one included, mxv lists nothing, deletes nothing and fails with that record's error, because the record may name what looks orphaned; move the record aside and run the command again. Before each deletion, mxv lists again and deletes the item only when the listing still holds it. An item whose deletion fails has the state partly_deleted, its row names the paths that are gone and gives the error, mxv goes on with the next item, prints every row, and then exits with the code of the first error.

Usage: mxv repair [OPTIONS] [NAME]

Arguments:
  [NAME]
          The name of the workspace or archive whose records to repair

Options:
      --orphans
          List what no record names and delete its run files and run records. phase's sweep first stops the processes and removes the containers, networks and run volumes that a run record names

      --delete-aside
          With --orphans, delete the archives that a repair moved aside and the ignored files that no archive names, which hold the only copies of their files

      --delete-volumes
          With --orphans, also delete the docker volumes that hold the data of each workspace id that no record holds

      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv repair sample --dry-run
          Print what repairing the records of sample would do

  mxv repair --orphans --delete-aside --dry-run
          Print what deleting the archive leftovers that no record names would delete

Effects: destructive, idempotent, closed-world.
