Create, archive and restore task workspaces that span several git repositories

Usage: mxv [OPTIONS] <COMMAND>

Work in a workspace:      new, add, list, show, cd
Run a workspace's app:    up, down, restart, status, logs, exec, run, ports
Put a workspace away:     archive, restore, repair, remove
Free disk space:          clean
Free memory:              reclaim, pin, unpin
Explore the commands:     commands, schemas
Review how mxv is used:   self
Install mxv's skill:      skills
Set up shell completion:  completion

Options:
  -h, --help     Print help (see more with '--help')
  -V, --version  Print version

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `mxv --help` describes them.
Topics: exit-codes. `mxv help <TOPIC>` prints one.
Next: mxv <COMMAND> -h
