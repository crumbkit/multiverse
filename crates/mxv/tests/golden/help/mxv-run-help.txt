Run an app's processes, or one command in the app's environment

Usage: mxv run [OPTIONS]

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv run
          Start the current app's processes

Effects: destructive, not idempotent, open-world.
Output: no result on standard output, and --json prints a failure as JSON.
