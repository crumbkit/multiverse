Manage the host ports that a workspace holds

Usage: mxv ports [OPTIONS] <COMMAND>

Commands:
  reset  Give a stopped workspace new host ports, each different from the port it held

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `mxv ports --help` describes them.
