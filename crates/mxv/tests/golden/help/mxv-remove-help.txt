Remove a workspace's clones with their branches, its directory and its record.

Remove fetches nothing. It counts a clone's unpushed commits against the clone's own remote branches and the heads and tags that its mirror last fetched from origin, and a refusal names how long ago the mirror fetched.

When no workspace has the name, or with --archived no archive, there is nothing to remove, so mxv changes nothing and the result's state is unchanged.

Remove holds the workspace's lock from before it stops the units until after it deletes the last docker volume, so a removal that meets a command that holds the lock for more than 5 seconds fails with mxv::workspace::busy and deletes nothing. After the question, it reads the workspace again, and when the workspace changed, or a unit runs that --force did not allow it to stop, or docker holds a volume that the question did not name, it deletes nothing and fails with mxv::workspace::changed or mxv::workspace::running. A process outside phase whose working directory is in the workspace refuses the removal with mxv::remove::in_use, and --force overrides the refusal and names the process in its question; the shell that runs mxv remove does not count, and a background job of that shell does. With --delete-volumes, the question names the docker volumes that the removal deletes.

With --archived, mxv holds the lock, reads the archive again after the question, and deletes only the archive that the question was about. When the archive is another one, such as a new archive of the same name after a restore, or is no longer finished, or docker holds a volume of it that the question did not name, mxv deletes nothing and fails with mxv::archive::changed. With --archived and --delete-volumes, the question names the docker volumes that the deletion deletes.

Usage: mxv remove [OPTIONS] <NAME>

Arguments:
  <NAME>
          The name of the workspace to remove

Options:
      --archived
          Delete the archive of this name and its pins, instead of a workspace

      --force
          Discard uncommitted changes, untracked files, ignored files such as .env and a clone's stashes, and stop running units; an unmerged branch and the workspace's volumes are still kept

      --delete-volumes
          Delete the workspace's docker volumes and the data in them

      --delete-unmerged
          Delete branches with unmerged commits, commits on a detached HEAD, and a clone's commits that origin does not hold

      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv remove reading-list --dry-run
          Print what removing the workspace reading-list would delete

Effects: destructive, idempotent, closed-world.
