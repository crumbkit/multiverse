Remove a workspace's checkouts, its merged branches, its directory and its record

Usage: mxv remove [OPTIONS] <NAME>

Arguments:
  <NAME>
          The name of the workspace to remove

Options:
      --force
          Remove checkouts with uncommitted or untracked changes, and delete unmerged branches

      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv remove reading-list --dry-run
          Print what removing the workspace reading-list would delete

Effects: destructive, not idempotent, closed-world.
