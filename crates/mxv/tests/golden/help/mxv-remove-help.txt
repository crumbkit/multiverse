Remove a workspace's checkouts, its merged branches, its directory and its record.

Remove fetches nothing. It counts a clone's unpushed commits against the clone's own remote branches and the heads and tags that its mirror last fetched from origin, and a refusal names how long ago the mirror fetched.

When no workspace has the name, or with --archived no archive, there is nothing to remove, so mxv changes nothing and the result's state is unchanged.

Usage: mxv remove [OPTIONS] <NAME>

Arguments:
  <NAME>
          The name of the workspace to remove

Options:
      --archived
          Delete the archive of this name and its pins, instead of a workspace

      --force
          Discard uncommitted changes, untracked files, ignored files such as .env and a clone's stashes, and stop running units; an unmerged branch and the workspace's volumes are still kept

      --delete-volumes
          Delete the workspace's docker volumes and the data in them

      --delete-unmerged
          Delete branches with unmerged commits, commits on a detached HEAD, and a clone's commits that origin does not hold

      --dry-run
          Report what the command would change, and change nothing

      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv remove reading-list --dry-run
          Print what removing the workspace reading-list would delete

Effects: destructive, idempotent, closed-world.
