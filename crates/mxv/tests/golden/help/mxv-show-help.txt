Show workspaces by name, in the order given

Usage: mxv show [OPTIONS] <NAME>...

Arguments:
  <NAME>...
          The names of the workspaces to show, separated by spaces

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  mxv show reading-list
          Show the workspace reading-list

Columns:
  name    The workspace's name, which is also the name of its directory and of its checkouts' branch.
  branch  The branch that the workspace's checkouts were created on.
  path    The workspace's directory, which `mxv cd` prints.

Columns that --long adds:
  repositories  The top-level directory of each repository that the workspace checks out.

Effects: read-only, closed-world.
