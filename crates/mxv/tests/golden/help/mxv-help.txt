Create, archive and restore task workspaces that span several git repositories

Usage: mxv [OPTIONS] <COMMAND>

Work in a workspace
  new       Create a workspace with its own clone of each repository, on a new branch from the freshly fetched origin
  add       Add a clone of a repository to a workspace, on the workspace's branch
  list      List the workspaces
  show      Show workspaces by name, in the order given
  cd        Print the directory of a workspace or of one of its checkouts, so `cd "$(mxv cd NAME)"` resumes it

Run a workspace's app
  up        Start a workspace's units from its mxv.toml, in dependency order, and wait until each is ready
  down      Stop a workspace's units with SIGTERM, then SIGKILL after 10 seconds
  restart   Stop a workspace's units and start them again
  status    Report whether each unit of a workspace is running, exited or stopped
  logs      Print the last lines of a unit's log, and follow it with --follow
  exec      Run a one-off command in the context of a running unit, and exit with its exit code
  ports     Manage the host ports that a workspace holds

Put a workspace away
  archive   Archive a workspace, so restore can rebuild it at the same commits
  restore   Rebuild an archived workspace at its archived commits
  remove    Remove a workspace's checkouts, its merged branches, its directory and its record

Free disk space
  clean     Delete the disposable directories, such as target/ and node_modules/, of idle workspaces

Free memory
  reclaim   Stop idle workspaces to free memory, or delete their build output to free disk, until the need is met
  pin       Keep mxv reclaim from stopping a workspace
  unpin     Let mxv reclaim stop a workspace again while it is idle

Explore the commands
  commands  Explore mxv's commands
  schemas   Explore the JSON documents that mxv prints

Review how mxv is used
  self      Review mxv's own use

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `mxv help <TOPIC>` prints one.
