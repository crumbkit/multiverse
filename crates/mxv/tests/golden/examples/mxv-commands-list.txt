PATH               ABOUT
mxv                Create, archive and restore task workspaces that span several git repositories
mxv new            Create a workspace with its own clone of each repository, on a new branch from the freshly fetched origin
mxv add            Add a clone of a repository to a workspace, on the workspace's branch
mxv list           List the workspaces
mxv show           Show workspaces by name, in the order given
mxv cd             Print the directory of a workspace or of one of its checkouts, so `cd "$(mxv cd NAME)"` resumes it
mxv up             Start a workspace's processes from its mxv.toml, in dependency order, and wait until each is ready
mxv down           Stop a workspace's processes with SIGTERM, then SIGKILL after 10 seconds
mxv restart        Stop a workspace's processes and start them again
mxv status         Report whether each process of a workspace is running, exited or stopped
mxv logs           Print the last lines of a process's log, and follow it with --follow
mxv archive        Archive a workspace, so restore can rebuild it at the same commits
mxv restore        Rebuild an archived workspace at its archived commits
mxv remove         Remove a workspace's checkouts, its merged branches, its directory and its record
mxv clean          Delete the disposable directories, such as target/ and node_modules/, of idle workspaces
mxv ports          Manage the host ports that a workspace holds
mxv ports reset    Give a stopped workspace new host ports, each different from the port it held
mxv commands       Explore mxv's commands
mxv commands list  List a branch of mxv's commands with their arguments, examples and columns
mxv schemas        Explore the JSON documents that mxv prints
mxv schemas list   List the JSON documents that mxv prints, with a description of each
mxv schemas show   Print the JSON Schema of each document
mxv self           Review mxv's own use
mxv self usage     Report the patterns in mxv's usage log where callers waste effort
mxv self figures   Work with the figures of each command in mxv's usage log
